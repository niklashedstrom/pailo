# Risker och öppna frågor

| Risk | Varför den spelar roll | Motåtgärd |
|---|---|---|
| Låg betalningsvilja hos privatpersoner | Intäkt per kund blir liten | Håll kostnad per hushåll mycket lägre, mät från dag ett |
| Folk vet inte vad de vill bygga | Ingen app blir byggd | Intervjun hjälper dem upptäcka problem, exempel och förslag |
| Byggstenarna räcker inte | Användare stöter på väggen | Ärlig gränskontroll, logga gap, bygg ut efter efterfrågan |
| Appen används inte efter några veckor | Ingen retention | Mät användning vecka 3, notiser och påminnelser |
| Begränsad tid (8–12 h/vecka) | Allt tar längre tid | Smal v1, Claude Code för implementation |
| GDPR och familjedata | Förtroende och juridik | Data i EU, RLS per hushåll, export och radering |
