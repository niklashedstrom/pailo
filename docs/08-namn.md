# Namn

**Beslut (2026-11-04): Pailo.** Domänen pailo.se är köpt.

## Varför

- Inget med exakt namnet hittades bland appar, mjukvarubolag eller varumärken vid kontrollen.
- Kort, två stavelser, fungerar på svenska och engelska.
- Känd svaghet: på engelska kan det läsas som "pail" (hink), och uttalet varierar ("PAJ-lo" / "PEJ-lo"). Bedömt som acceptabelt.

## Kvar att göra

- [ ] Sök "Pailo" i [TMview](https://www.tmdn.org/tmview) i klass 9 och 42, status Registrerad/Inlämnad
- [ ] Överväg pailo.app / pailo.com när det blir aktuellt internationellt
- [ ] Varumärkesregistrering hos PRV/EUIPO när AB bildas
